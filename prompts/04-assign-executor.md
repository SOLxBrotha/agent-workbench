# Assign one Executor task

Create one narrow Executor assignment from the owning Feature Parent's capability.

Use `templates/ASSIGNMENT.md` and add:

EXPECTED OUTPUT:
COMMIT AUTHORITY: <NONE | ONE ATOMIC COMMIT>

An Executor may research primary sources, inspect source, trace one path, reproduce one failure, implement bounded code, run existing checks, or review one exact diff. It must verify the base and scope first, touch only allowed paths, preserve protected paths, report evidence, and stop after the assigned output.

If a decision falls outside the assignment, require this return:

BLOCKER:
EVIDENCE:
DECISION REQUIRED:
NO FURTHER CHANGE

Do not use Executors to manufacture consensus or create independent workstreams.

Return the completed assignment and exactly one next action. Stop before executing the task.

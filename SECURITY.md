# Security policy

Do not open a public issue containing a vulnerability, credential, private repository content, or personal data. Use GitHub's private vulnerability reporting for this repository.

Never commit real tokens, keys, passwords, seed phrases, certificates, production identifiers, or captured environment files. Revoke and rotate an exposed credential before removing it from Git history.

The prompts and skills in this repository are instructions, not a security boundary. Use operating-system isolation, least-privilege credentials, restricted network access, protected branches, secret scanning, dependency review, and human approval for consequential actions.
